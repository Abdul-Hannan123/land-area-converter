# 🏡 Land Area Converter

A simple, responsive, and user-friendly **Land Area Converter** built using **HTML, CSS, and JavaScript**.

This project allows users to convert land measurements between different units such as **Marla, Kanal, Acre, Murabba, Square Feet, and Square Meter**. The interface is designed to work smoothly across **desktop, tablet, and mobile devices**.
